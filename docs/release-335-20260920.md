# 0.1.335 发布与部署记录

## 版本范围

本次包含已完成的 Chat / Responses 工具转换修复、充值页面独立入口开关与注册链接、控制台主题和背景修复。官方最新主分支的对照复现见 `protocol-tool-bridge-review-20260920.md`。

本地：517 项前端关键测试、29 项预览测试、lint、类型检查通过；apicompat 全包 race、相关 service / handler 与充值设置 GET/PUT 回归通过。完整单元、集成、lint、前端构建及 Linux 回退模拟由同一提交的 GitHub CI 验证。

## 部署约束

- 334 当前实例、PID 和旧连接保留，新增 335 使用内网 8094 和本机 pprof 6072。
- 保持旧机 40%、新机 60%。先新版本 1% / 334 99%；至少观察 180 秒、12 次守护检查、50 次业务成功后才允许全量。
- 全量后至少继续观察 360 秒；新增平台故障或公网健康失败触发回退到 334。上游错误 502/503不直接触发回退。
- 部署前备份原 unit、环境文件、Nginx upstream、守护状态与静态入口。环境只替换版本和监听端口，Grok 响应头超时保持 600 秒。
- 无数据库迁移，候选实例继续使用 `DATABASE_MIGRATION_MODE=validate`，不调整余额、价格、汇率与账号协议。
- 发布脚本复用已有 333 引擎，335 只定义版本、端口和目录。Windows 无 fcntl，WSL 不可启动，因此 Linux 回退验证以 GitHub CI 为准。
