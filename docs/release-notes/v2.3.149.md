# 2.3.149

## 新增：API Key 创建后可查看/复制，并用登录密码本地加密保存

- **创建后同会话可直接看**：创建或轮换 API Key 后，明文只放在页面内存里（不写 localStorage / sessionStorage / IndexedDB），列表该行直接显示完整 key 并提供复制按钮；刷新或登出即清除。
- **刷新后仍能自己看回来**：创建时默认勾选「允许以后用登录密码查看」，浏览器用登录密码派生密钥（PBKDF2-SHA256 310,000 次 + AES-256-GCM）在本地加密 key，服务器只存密文。以后复制时输入登录密码，**在浏览器本地解密**——服务器既不存明文，也不接收密码。
- 没有密文的老 Key：提示「无法找回，请轮换」，并给出一键轮换入口。
- 密钥轮换/删除时，同事务清理对应密文；第三方无密码账号自动隐藏该选项并说明原因。
- 列表接口只多返回一个 `has_sealed_secret` 布尔值，绝不返回密文、KDF 参数或哈希。

## 新增：归集目标地址锁定 + 关键操作通知

- **归集地址锁定**：启用签名分片后自动锁定归集目标地址；此后改地址必须走专用接口并同时通过 2FA、风险短语逐字确认与显式确认，写入审计（旧地址 → 新地址）。通用配置接口改地址会被拒绝（`SWEEP_DESTINATION_LOCKED`）；运行时还有一道兜底：锁与配置不一致时**一笔都不签**。
- **关键操作通知**：分片创建/重新分片/验证、签名器解锁、归集执行、归集地址变更等事件，可通过 Webhook（兼容 Bark）与邮件通知管理员；通知失败只记日志，不阻塞主流程，也不影响枚举/签名。
- 通知配置在加密设置里，Webhook URL 视为敏感值，公开配置视图返回空。
