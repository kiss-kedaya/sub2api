# v2.2.0

DeepSeek 搜索按次计费、分组搜索凭据可回显，并清理了一批死代码与格式问题。

## 1. DeepSeek 搜索改为「按次」扣费

此前只要命中网页搜索，计费就直接走「每次固定价」，分组里配置的「每千次搜索价格」永远不会生效。现在：

- 分组配置了每千次价格时，按 `搜索次数 / 1000 * 每千次价` 计费。
- 每一次搜索都会立刻扣费，不是攒够一千次才扣。
- 分组没配每千次价格时，仍按原来的每次单价计费。
- 显式填 0 表示免费。

## 2. 分组搜索凭据可以回显

DeepSeek 分组的「搜索专用服务地址 / 搜索专用 API Key」以前只能写入、读不回来，编辑时永远显示为空。现在：

- 服务地址正常回显。
- API Key 永不回传，只返回一个「是否已配置」的只读标记。
- 留空表示不修改已存的 key；只有勾选「清除已保存的搜索 Key」才会真正清空。

## 3. 编辑弹窗分组列表恢复完整字段

后台账号编辑弹窗的分组选择器此前显示空白。原因是详情接口在简单模式下把分组裁剪成只有 id/name/platform/status 四个字段，而选择器需要倍率、订阅类型才能渲染。现在返回完整分组对象，只继续隐藏 composite 分组。

## 4. 清理

- 删除三个没有任何调用方的内容审计采集函数。
- 删除一个永远返回 true 的请求改写占位开关。
- 修正三处 gofmt 格式问题与一处未检查的类型断言。

无数据库迁移。
