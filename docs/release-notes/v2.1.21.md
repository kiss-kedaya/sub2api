# v2.1.21

DeepSeek 搜索能力 + 平滑停机窗口。**含一条迁移（260）**。

## DeepSeek 搜索

- **分组级搜索单价**：`search_price_per_1k` 之前只对 Grok 平台显示，现在 DeepSeek
  分组也能设置。该字段本就存在于后端全链路，无需改表。
- **搜索专用凭据**（迁移 260）：`groups.search_provider_base_url` /
  `search_provider_api_key`。此前 `/v1/tools/search`、`/v1/tools/fetch` 只能用模型
  账号自带的 base_url 与 key，既吃模型账号额度，也无法指向独立搜索服务。现在分组
  可以单独配一套，留空则回落到账号（旧行为）。key 为敏感字段，永不回显。
- **web_search 工具注入**：配置了搜索单价的 DeepSeek 分组，向上游注入一个
  `web_search` function tool。模型对这个工具发出调用时，网关自己执行
  `/v1/tools/search`，把结果作为 tool result 附在响应里交给客户端。
  **不回填上游**，因此一轮上游请求最多触发一次搜索，不引入多轮循环。
  结果只保留标题/URL/摘要/日期，丢弃网页正文。

## 停机窗口

- 默认优雅停机等待从 **30 秒改为 60 分钟**，上限从 10 分钟放宽到 6 小时；
  两台主机的 systemd `TimeoutStopSec` 同步改为 70 分钟。

  网关有大量长连接流式（SSE）请求，一次对话可能持续几十分钟。`Shutdown`
  会先停止接受新连接、再等在途请求自然结束，30 秒的窗口会在流还没写完时
  直接杀掉进程，表现为用户侧断连。

## 部署说明

- **有迁移**：`DATABASE_MIGRATION_MODE=validate` 会拦住启动，需先跑
  `-migrate-only`。
- 本次按「新版本起空闲端口 → nginx 切权重 → 旧实例不停」的方式上线，
  旧实例保留到在途请求自然结束。
