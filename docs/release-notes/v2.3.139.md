# 2.3.139

## 安全

- **step-up 2FA 免授权窗口从 15 分钟缩短到 5 分钟**，与链上充值的授权窗口一致；因存在有效授权而**跳过验证码时不再静默**——响应头返回 `X-StepUp-Skipped` / `X-StepUp-Remaining`，控制台右下角常显「已跳过 2FA 验证 · 剩余免授权 4:32」，倒计时归零自动消失。所有敏感操作复用同一提示。
- 2FA 绕过面逐条复核并留档：路由分类表（未归类 fail-closed）、组级守卫、19 处 handler 级校验、机器凭证双层拒绝、TOTP 未启用、设置读取失败、跨会话绑定，全部不可绕过；跳过头只在确实使用授权时下发（防误报）。
- **TOTP 安装密钥改为部署配置优先**：`security_secrets.totp_encryption_key` 从数据库迁移到部署 env，数据库行作为过渡回退；缺失 env 时回退数据库并告警，不会导致 2FA 失效。

## 登录

- 修复「改过账户邮箱后，已绑定的 GitHub/Google/OIDC 登录报 `oauth identity belongs to a different email`」：已绑定的第三方身份以绑定关系为准，账户邮箱变更不再把本人锁在门外；provider 侧邮箱漂移只记日志，跨用户抢占仍由 ownership 冲突拦截。

## 计费

- Seedance 视频支持按秒/按次计费：修复调度快照丢失 `openai_capabilities`、`tokenBilled` 硬编码问题，按实际选中分组计价。

## 密钥与前端

- 智能路由密钥可绑定超过 10 个分组：放宽 `api_key_group_routes.position` 的 1..10 约束（迁移 330，保留 `position >= 1`），分组 ID 逐个校验存在性与绑定权限，并发冲突限定唯一键重试。
- 个人资料页不再显示第三方身份的 subject 掩码前缀（哈希化后对用户无意义）。
- IP 白名单支持「一键填入当前 IP / 常用 IP + 归属地展示 + 3 秒确认」，并加固：服务端缓存按「用户 + 当前 IP」区分（换网不再返回旧出口 IP）、非法 IP 过滤、地区字段裁剪、`Cache-Control: no-store`、IPv6 大小写去重、未命中限流 10 次/分。
- 用户仪表盘的快捷入口修复剩余不外跳路径（简易模式下隐藏 `/redeem` 等被守卫弹回的入口），卡片补齐键盘可见焦点。

## 说明

- **含数据库迁移 330**：部署顺序必须是 `-check-migrations`（只读）→ `-migrate-only` → 起新 colour → 切权重。
- 回滚：切回 2.3.138 二进制；迁移 330 只放宽约束，回滚无需回退数据。
