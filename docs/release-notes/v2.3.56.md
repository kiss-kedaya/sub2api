# Sub2API 2.3.56

## 链上直充：支持主网币 ETH / BNB

- Ethereum 可选 ETH、BSC 可选 BNB，与 USDT/USDC 并列；同一收款地址、同一二维码，提示文案随币种变化。
- 原生币按**交易级别**判定（`to` 命中收款地址且 `value > 0`），不走 ERC-20 日志；复用同一套幂等键，不另起一本账。
- **按成交时刻市价结算**：默认 Binance `ETHUSDT`/`BNBUSDT`，60 秒缓存、3 次退避重试、报价超过 10 分钟视为不可用。取价失败不入账，订单保持 pending，恢复后自动补账；绝不按过期价或默认价结算。
- 订单创建后金额永久冻结，重放不重新取价。
- 归集支持原生币，并预留 gas（2×21000×gasPrice），不会把余额扫成 0 卡死后续归集。
- 原生出账纳入 `scanWalletOutflows`：热钱包被转走原生币会走同一套告警。
- 扫描默认按区块游标逐块进行，可切换到按地址查询以降低 RPC 消耗。

## 迁移

- `314`：原生币充值的结算价、取价时间、价格来源三列。

## 升级注意

- 新二进制启动前会校验迁移，**必须先 `-migrate-only` 再重启**。
- small 的 `/app/sub2api` 是单文件挂载：新二进制放数据目录（`/app/data/sub2api.new`）跑迁移，再替换主文件。
