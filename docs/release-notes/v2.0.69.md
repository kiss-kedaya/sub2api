# v2.0.69

- 使用记录能看到还没结束的请求：首字、已运行时长、输入和输出 token。费用行是预留余额，不是最终价格。1 秒内结束的请求不写 Redis。
- 扫描器才会打的路径回空 404，并记下来源。正常对话、后台、支付回跳、画布不受影响。
- Codex OAuth 历史里有网页搜索记录但工具被清空时，补只读 web_search。本来没工具时不让模型真的去调。压缩请求不动。
- Grok 返回空的完成帧时换号。Anthropic 思考块带签名。流转成 Chat 时，心跳不再被客户端当成断流，拒绝内容进 refusal。
- 旧式 function 调用和结果按同一对 id 送出，不再用函数名当 id。加密内容校验失败时按原内容重试一次。
- WebSocket 从第 2 轮起按当前分组价计费。Key 换组、查询失败、平台或订阅类型变了，仍用建连时的分组。
- 渠道监控样本不够时保持未知。Cline 和 Command Code 走现有 OpenAI 兼容链。Cline 的 Responses 入站先转成 Chat。
- 出站 HTTP/2 健康检查改用标准库，超时数值不变。OpenAI 专用 HTTP/2 仍然不发空闲探测。

数据库迁移 255 只放宽平台约束，不改已有行、不改余额。生产环境仍保持 validate，部署时单独执行迁移。配置项默认值不变。二进制可回滚到 2.0.68；迁移放宽后旧二进制仍能启动。
