# v2.2.11

修复 Grok 安全拒绝未扣费、同一会话反复出站的问题。

- 识别完整和缩短的 `Failed check: SAFETY_CHECK_TYPE` 响应；保持上游 403，不再换号重试。
- Chat Completions、Responses、Anthropic Messages 三个文字入口在普通错误返回时执行固定单价结算，写入按次使用记录。
- 拒绝后持久屏蔽当前用户的该会话；后续同会话在选号前由平台返回 403，不再请求上游或重复扣费。切换模型或文字协议仍受屏蔽。
- 单价沿用分组设置，默认 0.10 USD/次；0 表示不收费，但仍屏蔽被拒会话。IP 黑名单和账号权限拒绝不作为安全拒绝收费。
- 增加真实 handler 回归，验证首次只出站一次、固定价不乘倍率、第二次本地拦截与不重复记账。

无数据库迁移。回滚可切回上一版实例；已屏蔽会话数据保留。
