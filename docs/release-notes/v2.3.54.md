# Sub2API 2.3.54

## 账号：上游余额不再显示「读取失败」

- 识别为 Sub2API / New API 的上游，余额读取失败不再回写失败状态：保留上一次成功的数值，按 1s / 3s / 9s 退避重试，下一轮继续，界面上不再出现「读取失败 / HTTP 403」。
- 401 / 403 / 429（上游明确拒绝）走 1 分钟慢速重试，避免被上游按 IP 统计失败认证。
- 删掉账号列表左侧那列「上游余额」（显示探针原始结果与「查询失败，请检查 URL、凭据和提取器」的那列）；右侧显示余额的列保留。
- 余额查询与上游识别打通：识别出 Sub2API / New API 后自动填好 URL、凭据与提取器，默认 10 分钟刷新一次。

## 密钥：自动封禁机房 IP 改成开关

- 「自动封禁机房 IP」从一次性按钮改为每个密钥的开关；开启后每 5 分钟检查该密钥最近使用的 IP，把判定为机房/代理的 IP 追加进它的 IP 黑名单。
- 只加不删；判定服务不可用时跳过该密钥（放行）；单个密钥失败不影响其它密钥。
- 开关值随「IP 限制」一起生效：关闭 IP 限制时不会出现「后台继续追加、下次保存又被清空」。
- 新增迁移 `313`：`api_keys.auto_block_datacenter_ips`（默认 false）。

## 设置页：Dense 行收尾

- 外观页签重写为 Dense 行：主色 / 中性色保留右侧色板，字体 / 圆角 / 默认模式走行内摘要 + 展开区选择。
- Claude OAuth「System Blocks」内层表单、联网搜索服务商展开后的字段区，一并收成 Dense 行。

## 其他

- 网关日志新增真实客户端地址字段 `client_ip`（此前恒为 127.0.0.1）。
- 站点出口新增每客户端连接/速率上限（200 并发 / 200 rps，突发 400），超限返回 429。
