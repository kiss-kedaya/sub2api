# v2.2.4

Grok 安全拒绝的扣费口径从「0.1 × 组倍率」改为「分组可配的固定单价」，
默认仍是 0.1 USD/次，配置入口在 Grok 分组设置里、模型白名单上方。

## 1. 变更

- 新增分组字段 `grok_moderation_refusal_price`（`decimal(20,8)`，可空）。
  - `NULL`：使用默认 0.1 USD/次。
  - `0`：显式关闭该扣费。
  - 其它值：按该值直接扣费。
- 扣费**不再乘分组 `rate_multiplier`**：运营按「每次多少钱」定价，避免倍率把罚金放大或缩小。
- 迁移：`backend/migrations/261_group_grok_moderation_refusal_price.sql`。

## 2. 行为

命中 `SAFETY_CHECK_TYPE` 安全拒绝时：

1. 立即结束本次请求，不再对同一会话重复调度上游。
2. 按分组单价对用户扣费（默认 0.1 USD/次）。
3. 会话在该分组内封锁 24 小时。

三个入口保持一致：`/v1/messages`、`/v1/chat/completions`（含 raw 转发）、`/v1/responses`。

## 3. 后台

分组编辑页（platform = grok）新增「Grok 安全拒绝扣费」区块，位置在模型白名单上方：

- 输入框：每次扣费（USD）
- 占位提示：默认 0.1
- 留空 = 使用默认 0.1；填 0 = 不扣费
