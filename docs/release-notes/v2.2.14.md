# v2.2.14

- Grok 返回实际内容安全拒绝 403 或 `blocked by global ip blacklist` 403 时，保留上游状态码和响应 JSON，按分组固定价结算一次且不重试；同一会话后续请求在出站前拦截且不再收费。
- 覆盖 HTTP 200 的 SSE 终态内嵌 403：Responses、Chat Completions、Messages 及 WebSocket 都按真实拒绝结算并封锁会话；非流式保留 403，流式保留原终态帧。
- 识别不带 `SAFETY_CHECK_TYPE` 的标准拒绝文案；429/5xx 不套用拒绝收费或会话封锁。
- 集成上游 PR #8139：`response.queued` 与 `response.metadata` 不再被当作模型输出，后续 overload 保持可安全 failover。

无数据库迁移。
