# v2.2.35

修复 DeepSeek 独立搜索配置与 Codex 实时搜索兼容问题。

## 修复与功能
- 修复鉴权缓存丢失搜索配置、搜索路径重复拼接 /v1 及默认模型失效引起的 404/502。
- 搜索结果交回模型继续流式回答，返回标准搜索事件及真实来源。
- 兼容混合 Responses 与 Chat Completions 账号，沿用各自协议。
- 成功搜索按次追加费用，保留各轮模型 Token 用量及取消、断连和错误配对处理。

## 升级注意
- 不包含 Bitget 代付，无新增数据库迁移，不修改已有搜索定价。
- 仅缓存模式 external_web_access=false 暂不支持并明确报错。
