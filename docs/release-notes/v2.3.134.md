# 2.3.134

## 支付（本版重点，线上故障修复）

- **易支付回调兼容真实服务商变体**：真实易支付（ylyun.net 等）回调会额外携带 `bill_trade_no` 等由支付方生成的字段。旧实现用「未知参数一律拒绝」白名单，直接返回 400 `verify failed`，导致 **支付成功但订单永远 PENDING**（上一家变体同样原因）。
- 改为**宽容解析 + 签名强校验**：签名基串覆盖全部非空参数，任何追加/篡改/重放都会签名失效；强制业务必需字段（`pid`/`trade_no`/`out_trade_no`/`money`/`trade_status`/`sign`）存在且唯一；重复 key 继续拒绝。
- 业务判断只读解析后的单值 map，不按 `&` 手工切分原始 query，`return_url` 内嵌 `trade_status=TRADE_SUCCESS` 之类的参数夹带（上游 #7881）无法升级为顶层参数。
- 回归测试：变体字段可验签、未签名追加参数被拒、必需字段缺失被拒。
