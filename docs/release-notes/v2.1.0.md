# v2.1.0

- 使用记录里的在途请求不再每 2 秒重拉整表，时长也不再每秒跳。点刷新才更新。在途行标成「正在请求」。
- 在途请求默认折叠。不点开，不会向服务器要这些记录。
- 使用记录和错误记录可以按请求 ID 搜索。
- 后台打开「在途余额预留」后会真正登记预留。费用有预留额才显示金额，没有就不再显示 $0。
- 在途行补上 API 密钥名、推理强度、入站端点和 IP。管理员还能看到上游端点。
- 1 秒内结束的请求仍不写 Redis。首字如果发生在第一次写入之后，再补写一次。

没有数据库迁移。生产环境保持 validate。余额预扣 hold 仍然默认关。二进制可回滚到 2.0.69。
