# 2.3.147

## 充值体验：检测到转账即入账，失败自动扣回

- **即时入账**：链上扫描首次观察到某笔充值就立即入账（不必等满确认数），到账记录标记为「临 时入账」；达到配置的最终确认数后自动转正，不再重复加钱。
- **失败自动扣回**：临时入账之后若交易不在规范链上（重组）、revert 或被替换，系统自动扣回该笔金额：
  - 扣回幂等：同一笔只扣一次，扣回过的交易永久不再入账；
  - 余额不足时允许余额变负并记录原因，不反复扣；
  - 写审计 `DEPOSIT_PROVISIONAL_REVOKED`，并给用户推送「该笔充值未最终确认，已回滚」。
- **开关**：`crypto.config.instant_credit_enabled`（老配置默认开启，可一键关回「确认后入账」的旧行为）、`instant_credit_min_amount`（低于该金额仍按确认数入账，默认 0）。
- **安全窗口**：0 确认入账前先跑头部安全扫描，保持原有的热钱包异常流出防护。

## 充值页：到账状态与预估时间

- 网络状态徽标改为按真实数据分级（可充值 / 网络较慢 / 到账延迟 / 暂停 / 异常 / 状态检测中），**数据过期一律按「状态检测中」处理**，不再沿用旧状态误报「到账延迟」；切换网络或窗口重新聚焦时自动静默刷新。
- 每个网络显示**预估到账时间**（即时入账网络显示「即时到账」），并说明「若交易最终失败会自动回滚，请以完成确认为准」。
- 接口新增 `eta_seconds` / `backlog_seconds` / `required_confirmations` / `instant_credit`；数据缺失返回 null，不瞎猜。
