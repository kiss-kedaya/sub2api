## 界面：Dense 设置行收尾

- 系统设置页：网关页签的 Beta 策略、OpenAI Fast/Flex 策略逐条成行；其余页签的人机验证、LinuxDo、条款、邀请返利等收进 Dense 行；「指定 IP 提示与限流」组件重做。#287 #289
- 账号：添加账号、批量编辑两个弹窗的设置项与编辑弹窗统一成行；编辑弹窗里的配额卡片、Responses/Compact 的两块字段也收进行内。#288 #290

- 手机宽度（<640px）：文本类输入框换到名字下一行，长设置名换行显示不再被截断；行内摘要也不再被挤成一个字。#293

## 账号管理：上游类型与上游余额

- API Key 账号多一个上游徽标：Sub2API / New API / OpenAI 账单 / 官方 / 自定义 / 未识别。#292
- 新增「上游余额」列，默认显示：主数字是密钥剩余额度，账户余额单独一行；无限额度显示「∞ 无限额度」；读取失败、旧数据、按默认比例换算都有明确标注和提示。#292
- 账号详情「用量」页签里加上游余额区块。#292

## 网关

- 跨域响应现在把请求 ID 和三个 Kimi/Moonshot 缓存头暴露给浏览器（`Access-Control-Expose-Headers`）。#294
- Chat Completions 的响应体与流式 usage 分片补上 `usage.cache_creation` 的 5m/1h 分档（来自上游响应头，只做加法）。#296

## 计费与同步

- 上游模型自动同步：读取失败时保留原有模型列表，不再清空（此前失败会把账号对所有模型放通）。同时修正「重试三次」实际只重试一次的问题。#295

## 密钥
