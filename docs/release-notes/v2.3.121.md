# 2.3.121

## 安全加固

- **旧版全权管理员 key 退役**：`POST /settings/admin-api-key/regenerate` 固定返回 403 `LEGACY_ADMIN_KEY_RETIRED`，不再生成或改写全权密钥；`GET` 仍返回 masked key 并标注 `deprecated` + 迁移提示；启动日志检测到旧 key 时告警（不打印密钥）。旧 key 的认证路径保持不变，存量可用，仅停止新建。
- **敏感管理写操作补齐 step-up（2FA）**：`PUT /admin/payment/config`、支付渠道实例增删改、退款与退款查询、`PUT /admin/settings`、`DELETE /admin/users/:id`、`POST /admin/users/:id/balance` 全部要求近期二次验证；`PUT /admin/users/:id` 仅在携带密码修改时门控，普通资料编辑不打断。
- 受限管理密钥权限目录移除 `payment.refund`（该操作已强制 step-up，授权后必然 403 没有意义）。

## 说明

- 机器凭据（管理员 API Key）在 `step_up_enabled=true` 时对上述操作一律 403 `STEP_UP_ADMIN_API_KEY_FORBIDDEN`，与既有 step-up 路由语义一致；`step_up_enabled=false` 的部署行为不变。
- 前端已同步：删号/批量删号/余额/退款/退款查询/支付保存会弹 TOTP 并自动重试，旧 key 卡片改为迁移提示。
- 无数据库迁移、无新增配置项；回滚 = revert `b709d84d9`。
