# 2.3.90

## 修复

- **用量导出稳定性**：分页 100 -> 1000（后端上限），11370 行从 114 次串行请求降到 12 次；每页最多重试 3 次并退避，取消时立即停止。之前一页失败就整个导出中止，表现为「跑到 2% 就 Export Failed」。

## 新功能

- **渠道可单独设置 Ultrafast 档位倍率**：`channel_model_pricing` 新增可空列 `ultrafast_multiplier`，管理端渠道定价卡片增加输入。留空沿用模型自带值（Opus 5.5 为 6x），填正数只影响该渠道该模型的 ultrafast 档。

## 迁移

- 新增迁移 `315_channel_pricing_ultrafast_multiplier.sql`（加列，可空，无需回填），部署前需先跑 `-migrate-only`。
