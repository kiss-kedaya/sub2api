# v2.3.110

## 修复

- 修复渠道监控中“历次降智检测”记录的对齐方式，时间顺序和上方时间轴保持不变。
- 修复大批量使用记录导出遇到 429 后整份失败：按 `Retry-After` 等待后重取当前页；检测分页总数、页长、行数和重复记录，发生 OFFSET 漂移时最多重取一次，避免生成残缺 CSV；离开页面会取消等待。
- 导出按钮会提示当前处于限流等待，超出等待预算时提示缩短日期范围或稍后重试；不提高 API 限流阈值。
