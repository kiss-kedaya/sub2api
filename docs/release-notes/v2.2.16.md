# v2.2.16

管理员关闭双因素认证改为验证当前认证器的六位动态码。

## 安全与交互
- 管理员关闭 2FA 时，登录密码、邮箱验证码和已有二次验证授权不能代替当前 TOTP 验证。
- 启用 2FA 继续沿用密码、二维码和动态码确认，不新增服务器一次性授权码要求。
- 关闭全局 2FA 或敏感操作二次验证要求当前会话已通过 TOTP；取消或验证码错误时不保存。
- 加固认证器绑定、关闭及管理员角色变更的并发保护，移除 TOTP 调试日志中的密钥前缀。
- 增加服务器端管理员 2FA 恢复命令，不修改密码、角色或全局设置。

## 升级注意
- 无新增数据库迁移，前后端需配套更新。
- 运维恢复命令不会自动撤销尚未过期的访问令牌。
