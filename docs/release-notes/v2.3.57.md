# Sub2API 2.3.57

## 同 IP 多用户风控（自动加入提示与限流）

四个条件同时成立才动作：

- 同一来源 IP 在 **5 分钟**内使用 **4 个不同用户**的 key（按用户 ID 去重，一个用户多把 key 只算 1）；
- 该 IP 判定为**机房/代理**（家宽、公司共享出口不动作；分类失败或超时不动作）；
- 涉及的 key **创建已满 30 天**（新 key 不纳入）；
- 只统计网关业务请求，健康检查、探针、静态资源不计。

命中后：IP 自动加入「指定 IP 提示与限流」列表，涉及的 key 置为 inactive（不删除、不动上游账号），并在 key 上带风险标记；用户在 key 页面点「轮换密钥」即可生成新 key 并恢复可用。

## 其他

- 自动加入开关默认由后台控制，部署后先保持关闭，观察命中情况再打开。
