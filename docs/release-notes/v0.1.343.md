## 新功能

- OpenAI 平台新增账号类型 **Cloudflare Workers AI**：填 Account ID + API Token，不手填 Base URL；三种入口都转 Chat Completions。

## 修复

- 修前：Cloudflare Token 可能被发到 `api.openai.com`。
  修后：WebSocket 和原生 Responses 路径不再发送该 Token。

## 风险与已知问题

- `typesafe/jev` 不是对话模型，本版不会让它出字。测 Cloudflare 要用 Workers AI 对话模型，例如 `@cf/meta/llama-3.1-8b-instruct`。
