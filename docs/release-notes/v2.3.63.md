# Sub2API 2.3.63

## 归集：gas 价格下限与同 nonce 替换（修 1 wei 交易卡死）

- **根因**：`Pool.GasPrice` 轮转端点、取第一个成功返回的结果，只校验 `> 0`。BSC 端点池里混有返回 `0x1` 的节点，于是回到 1 wei，交易签名后广播、永远进不了块，还占住地址的 nonce 0，把后续归集全堵死。
- **修复**：
  - 每条链设最小可接受 gas price（BSC 0.05 gwei、Polygon 30 gwei、Ethereum 1 gwei 等），低于下限钳到下限；0/负数/空视为无效；
  - 多端点采样取上中位数（30s 缓存），不再被单个坏端点带偏；
  - 归集中途发现同地址同 nonce 的历史交易低于下限时，用更高 gas price 重签替换（至少 +12.5%），先落库再广播；
  - 预算与下限的关系在规划阶段校验，cap 连一笔转账都覆盖时直接报错并跳过该链，不再静默延后。
