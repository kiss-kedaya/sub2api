# 2.3.145

## 优化：账号列表「上游声明倍率」刷新不再要求 2FA

- **问题**：管理端账号列表「上游声明倍率」列每行有一个刷新图标，点一次弹出一次 2FA 验证，正常运营没法用。
- **原因**：该动作走 `POST /api/v1/admin/accounts/:id/upstream-billing-probe`（批量版为 `.../upstream-billing-probe/batch`），因为是 POST 被「账号写操作」规则归入 step-up 必须项。但这两个接口只向上游探测并返回**公开的倍率数字**，不返回、不写入任何上游凭证。
- **修复**：在 `adminroutepolicy` 的 secret-free 精确清单里显式分类这两条路由（新增原因码 `upstream_declared_rate_probe_no_secret`）。
- **保持不变的**：启用开关 `PUT /accounts/:id/upstream-billing-probe` 与全局设置 `PUT .../upstream-billing-probe/settings` 仍然要求 step-up —— 改配置依旧要 2FA。

## 说明

- 无数据库迁移，无前端改动。
- 路由覆盖测试要求每条 admin 路由都被显式分类，本次已同步更新。
- 回滚：切回 2.3.144。
