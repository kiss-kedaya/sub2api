# Sub2API 2.3.53

## 调度：中转站上游与自定义错误码账号不再被自动临时停调

- 网络类错误（DNS / TCP / TLS / 代理失败）此前会绕过「自定义错误码」，直接把账号停调 10 分钟。现在这类错误对**中转站上游的 API Key 账号**和**开启了自定义错误码的账号**不再停调，只做失败转移。
- 你配置的自定义错误码规则（仅对选中的错误码停止调度，持续 30 天）与临时不可调度规则行为不变。
- 其他账号（官方域名、OAuth、上游类型）的自动停调行为完全不变。

## 账号详情

- 「临时不可调度」弹窗补上「原始原因」：网关自己写入的停调记录（如 transport error）没有匹配规则，此前弹窗里看不到原因。
