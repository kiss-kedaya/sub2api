# v2.3.0

## Nuxt SSR 与统一构建

- 管理端与用户端接入 Nuxt/Nitro SSR，Node BFF 负责会话、CSRF 与同源管理 API 代理。
- 保留 Go `-tags=embed` 的 SPA 回滚页，并用前端清单、版本、commit 与哈希绑定 SSR 和 Go 制品。
- 发布流程增加 SSR 制品、健康检查、隐私扫描和前后端版本一致性校验。

## 管理端交互与性能

- 用户、分组、账号、使用记录等列表减少二层数据首屏加载，支持按需加载和批量配额查询。
- 大列表关联对象改用紧凑摘要，导出兼容摘要字段，避免传输完整密钥、定价和订阅对象。
- 主题、品牌图标、深色模式、移动端布局与樱花视觉统一到 Nuxt UI 组件体系。

## 兼容与安全

- SSR 会话使用 HttpOnly cookie 和 CSRF 校验，前端不再把可用 bearer token 写入 SSR payload。
- 网关 `/v1/` 流量继续直连 Go；管理 API 通过固定后端 origin 的 BFF。
- 运行时缓存读取失败时容量显示未知，不把未知状态伪装成 0。
