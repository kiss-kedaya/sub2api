# Sub2API 2.3.5

## 修复

- 定时状态只有在成功加载并确认没有周期计划、也没有待执行单次计划时，立即切换才跳过确认框。
- 定时状态仍在加载或读取失败时继续显示确认，避免把未知状态误当成无计划，导致意外取消。
- 定时开关状态与确认策略增加专项回归测试。
- 稳定 request-capture 异步诊断测试：等待任务真正进入运行态，并排空前一条请求后再测下一轮 WebSocket，会话资源不再与后台 worker 竞态。

## 验证

- 定时状态/切换专项 Vitest：14/14 通过。
- `vue-tsc --noEmit` 与相关 ESLint 通过。
- 完整 GitHub Actions CI 与官方 Go、Nuxt SSR 制品检查。
- 不涉及数据库迁移，生产环境继续使用 `DATABASE_MIGRATION_MODE=validate`。

## 回滚

- old/new 使用独立候选实例与 SSR 目录；切流前保留 v2.3.4 upstream 与制品。失败时切回 v2.3.4，不覆盖现有运行目录。
