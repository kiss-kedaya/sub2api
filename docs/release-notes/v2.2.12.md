# v2.2.12

修正上游错误码归一，并阻止命中全局 IP 黑名单的会话继续请求。

- failover 耗尽时保留上游真实 5xx 状态码和错误信息；上游 500 不再被改成 529。仅上游明确返回 529 或协议明确报告过载时保留 529。
- 命中 `blocked by global ip blacklist` 后，当前会话立即返回 403 并持久封锁；后续同会话请求在选号和出站前拒绝，不记 Grok 固定价或用量账单。
- Grok 固定价为 0 时不再按安全拒绝的上游 token 用量收费；只有真实上游 403 才进入固定价与封锁路径。
- 会话封锁不再使用可复用的 `prompt_cache_key` 作为唯一身份，避免同一用户无关对话被永久连带封锁；支持 Grok 会话头和 `previous_response_id` 跨模型续拦。
- 补齐 WebSocket 拒绝处理，复用 HTTP 的会话封锁与固定价规则。
- 敏感数据检查仍拒绝发布秘密，但只输出命中位置和规则，避免检查日志泄漏原值。
- Go 升级到 1.26.10，修复标准库证书验证安全公告；前端锁定已修复的 `follow-redirects` 1.16.1。

无数据库迁移。
