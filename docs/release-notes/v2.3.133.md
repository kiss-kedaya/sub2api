## Key 体验

- 一次性明文档：1 秒强制展示后「我已保存」可正常关闭；「使用密钥」「导入到 CCS」改为叠层子弹窗，关闭子弹窗回到明文弹窗，明文与复制按钮始终可用。
- 创建 key 后可立即「使用密钥」，不再误报「请先分配分组」（创建/更新回执补齐完整 group）。
- 实例存在可用分组时拒绝创建无分组 Key（`400 API_KEY_GROUP_REQUIRED`），避免废 key。
- `/keys` 列表展示「待整改」角标与原因，页头显示待整改数量与「一键处理」；轮换/设置 IP 白名单后实时消失。
- 充值/兑换整改卡片不再显示门槛时间。
