## 新功能：分组降智检测

- 定时检测 runner 按分组开关，在该组最多探测 5 个可调度账号；降智的号暂停调度，恢复正常后自动放回。
- 管理端新增接口：`PUT/GET /admin/quality-check/groups[/:id[/results]]`。
- 渠道状态监控页新增「降智检测」设置卡片，可按分组逐项开关并查看状态徽章。
- 模型广场分组条目新增 `quality_status`（healthy / suspect），用户侧可见。

## 修复：禁用不安全的在线更新（对应 2026-09-26 事故）

- 修前：后台点「立即更新」会在**原位置替换正在运行的二进制**；如果新二进制启动失败，外部部署脚本会把流量切到一个已经死掉的端口，**整站下线**。
- 修后：`UPDATE_STRATEGY=disabled` 时后端直接拒绝 `PerformUpdate` / `Rollback` / `RollbackToVersion` 并返回明确错误；前端在禁止在线更新的部署下隐藏更新与回滚按钮并给出提示。
- 顺带修复账号表格横向溢出。

## 升级注意
