# Sub2API 2.3.3

## 性能与交互

- 优化 `/admin/accounts` 与 `/admin/usage` 大表格滚动：虚拟滚动窗口不再每次更新都重复测量 DOM，滚动与尺寸检测使用帧合并和去抖，减少回流和卡顿。
- 缓存数字、金额、日期格式化器，避免每个单元格重复创建 `Intl` 实例。
- 樱花背景改为缓存布局矩形，滚动时只平移可见装饰，不重复扫描整页元素，保留低密度、避开文字和 `prefers-reduced-motion` 行为。
- 账号用量单元格取消深层响应式遍历，改为批量数据替换时更新。
- 编辑账号支持悬停预取详情和空闲预热弹窗代码，点击后先复用已缓存数据。
- 编辑分组先打开可用弹窗，再后台补齐模型路由账号名称，并使用有限并发与名称缓存，避免逐个串行请求卡住交互。

## UI

- API 密钥智能路由分组默认折叠，仅保留主路由常显；展开后可查看完整候选顺序，并继续添加、上移、下移、删除。
- 智能路由操作按钮统一使用 Nuxt UI，补充明确的无障碍标签和 `type="button"`，避免误提交。

## 验证

- GitHub Actions 全量 CI 通过：前端类型检查、Vitest、Nuxt SSR 构建与认证页面契约、Go 测试、集成回归、构建、lint、安全扫描。
- 未修改版本以外的支付、鉴权、数据库迁移和生产配置；生产环境继续保持 `DATABASE_MIGRATION_MODE=validate`。
- Release 使用 GitHub Actions 官方制品，不使用本地构建物。

## 回滚

- 本版本仅合入前端性能与交互优化，部署前保留旧 Go/SSR 实例和 upstream；若真实页面或 API 验收失败，回切上一稳定版本，不覆盖运行目录。
