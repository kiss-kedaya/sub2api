# v2.1.25

分组定价区块拆分为「搜索定价」与「Grok Voice 定价」，并修复上版遗漏。

v2.1.24 删除重复字段时删多了：DeepSeek 的「搜索专用服务地址」和「搜索专用 API Key」被整组移除，导致新建/编辑分组时无法再配置搜索专用凭据。本版恢复这两项（各一份），并把原先混在同一个区块里的 Grok Voice 三项（realtime / TTS / STT）拆成独立的「Grok Voice 定价」区块。

- 区块标题：「搜索与 Voice 定价」→「搜索定价」，描述同步只提 web_search。
- 新建与编辑分组表单同步修复。

配置位置：管理后台 → 分组 → 新建/编辑分组 → 平台选 DeepSeek →「搜索定价」（搜索每千次价格 + 专用服务地址 + 专用 API Key）；平台选 Grok →「Grok Voice 定价」。

无新增数据库迁移。
