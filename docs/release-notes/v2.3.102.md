# 2.3.102

## 紧急修复

- **关掉 Grok 违规拒绝后的会话封禁**：上游判一次违规后，网关会把「这个会话」永久封禁，之后的请求直接在本地
  返回 403。实际拦住的远不止被拒的那个会话：线上每小时 2500～6000 次请求被本地封禁拦掉，而真正被上游拒绝的
  只有 35～120 次；用户被拒一次后，新开的会话也一起被拦，而且永不过期。
  - 现在封禁整体关闭：不再写新的封禁，以前写下的封禁一律不认，被封的用户升级后立即恢复。
  - 违规拒绝本身的固定收费不变（真正打到上游并被拒的那一次照收）。

## 同时包含 2.3.101 的内容（2.3.101 没有单独上线）

- **DeepSeek 聊天类请求体上限 48MB**：超过直接返回 `413 Request body too large, limit is 48MB`，不转给上游，不扣费。
- **DeepSeek 大请求（请求体超过 20MB）等上游最多 30 分钟**，其余请求仍是 65 分钟；到点返回
  `504 Upstream did not respond in time`，不重试、不换号、不扣费。

## 升级注意

- 无数据库迁移，无前端改动。
