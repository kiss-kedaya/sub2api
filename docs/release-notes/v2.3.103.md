# 2.3.103

## 修复

- **Grok 违规拒绝后的封禁改成只认对话内容**：2.3.102 把封禁整个关掉止血，这一版把它按正确的范围恢复。
  - 以前按请求头里的会话标识（`x-grok-conv-id`、`session_id` 等）封禁，而且永久有效。很多下游把同一个标识用在大量对话上，
    所以被拒一次，这个用户后面几百上千条请求（包括新开的对话）全被拦。
  - 现在不再看任何请求头，只看对话内容：被上游拒绝的那段对话，原样重发或者接着往下聊才会在本地拦住（不打上游、不扣费）；
    内容不同的对话、新开的对话不受影响。封禁 24 小时后自动解除。
  - 旧版本按请求头写下的封禁一律不认，之前被误封的用户不会再被拦。
  - 违规拒绝本身的固定收费不变（真正打到上游并被拒的那一次照收）。重复重发同一段被拒内容不再每次都扣。

## 升级注意

- 无数据库迁移，无前端改动。
