# 2.3.129

统一线上版本（此前 old/new 分别停在 2.3.126-rd / 2.3.105-rd）。包含 2.3.127 全部内容，并把撞号的迁移拆分为 323/324/325。

## 安全与合规

- 充值整改门禁：用户完成 API Key 轮换或设置 IP 白名单前，兑换码/充值中心/USDT 充值接口一律 403 `KEY_ROTATION_REQUIRED`（门槛时间 `security.key_rotation_cutoff`，开关 `security.key_rotation_gate_enabled`，被拦请求写审计）。
- 2FA 校验按账号 60 秒滑动窗口限 5 次（429 + Retry-After），前端倒计时禁用。
- 审计日志禁止后台清理、保留期 90 天；OAuth 登录与 2FA 挑战全路径审计。
- 支付渠道配置 AES-256-GCM 落库加密；crypto 签名审计补操作者归属。
- API Key 仅创建/轮换时返回一次明文，其余出口后端统一脱敏；管理员查看用户 Key 需 step-up。
- 个人资料补 GitHub/Google 登录绑定入口（前后端一致）。

## 业务

- 负余额清账与充值即时抵扣（`billing.debt_clawback_enabled`）。
- 同一用户扣费合并结算（默认关闭）。
- qwen3.8-max / qwen3.8-flash / qwen4-max 下架。
- 充值地址轮换能力。

## 迁移（必须 `-check-migrations` → `-migrate-only` 后再换二进制）

- 323 crypto 充值地址轮换（部分唯一索引）
- 324 user_debt / user_debt_clawbacks
- 325 crypto_signer_audit 操作者字段
