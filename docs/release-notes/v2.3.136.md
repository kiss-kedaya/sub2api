# 2.3.136

## 回滚 / 事故修复（重点）

- **彻底删除上游凭据 at-rest 加解密功能**（PR #497 引入）：`accounts.credentials`、`proxies.password`、`settings` 敏感项恢复明文落库，删除 SecretVault / credentials_secrets / proxy_secrets / settings_secrets / secrets_backfill / secrets-decrypt / managed_proxy_wire。
- 事故回顾：2.3.135 上线该加密后，网关部分路径把 `enc:v1:` 密文当上游 api_key 发送，导致全站 502 `Invalid API key` / `无效的令牌` 与 429 `Too many invalid authentication attempts`（峰值 20k+/分钟）；且回滚旧二进制无法解密已加密数据。生产已回滚 2.3.134、DB 解密回明文、清理调度快照、起干净实例恢复。
- 保留与本事故无关的既有 AES `SecretEncryptor`（TOTP 密文、插件、备份等）。
