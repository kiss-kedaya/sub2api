# Sub2API 2.3.66

## 汇总（含 2.3.65 全部内容）

- `GET /api/v1/settings/public` 增加 `Cache-Control: public, max-age=30`；前端失败后 30 秒内不再重试（`force` 可穿透）。掐掉登录页反复挂载造成的 429 自放大。
- 上游 `message_delta` 给 `input_tokens: 0` 这类占位值时，不再覆盖已上报的输入 token。
- 受管代理导入静态节点失败的问题修复（mihomo）。
- 渠道监控：缓存低于 30% 标记为 critical。

## 说明

- 无迁移。
- 设置项改动最多 30 秒后对浏览器生效。
