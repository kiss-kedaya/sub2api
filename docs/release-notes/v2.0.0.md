正式版本号 2.0.0，二开版本，不是上游官方发行版。

## 新功能

- 账号管理新增「上游余额」列，位于用量窗口右侧；支持手动刷新和可见行自动刷新。
- 账号「更多」新增用量查询配置：通用 / NewAPI / Sub2API / 自定义模板；支持独立凭据、超时、刷新间隔、请求头、声明式 JSON 字段提取。草稿测试不自动保存。

## 修复

- 凭据不回显；查询限制响应大小、并发、冷却和目标地址，阻止内网访问与 DNS 重绑定。
- 查询头展开前校验大小；Cookie 子值不会作为套餐名或单位回显；并发编辑不会撤回已轮换或已清空的查询密钥。
- 在上游响应出口隐藏余额不足、额度耗尽及财务明细错误，未提交响应统一返回通用 502；已开始的流用协议内通用错误终止。
- 一批异步/并发隔离修复：公告按会话、余额历史丢弃过期结果、API key 结果按 dialog user 隔离、备份继承的 S3 密钥先加密、自定义用量跨实例拒过期保存、自定义用量密钥旋转加库锁。

## 风险与已知问题

- **相对 0.1.354 没有新增数据库迁移。**
- 上游用量查询的安全边界在本版收紧（白名单是安全敏感项）。

## 升级注意

- 对照上游 v0.2.8 选择性手工移植 8 项修复，**没有整树覆盖二开**。
- 2.0 不代表重置数据、改动价格、自动映射模型或替换已有渠道配置。
