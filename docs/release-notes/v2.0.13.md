- 渠道状态用户页（V3 卡片）新增「历次检测」：每个开启降智检测的分组列出已产生判定的历史检测（只显示检测成功完成的记录，失败与无法判定的内部错误不外泄），鼠标悬浮某条即加载当时被检测的作品并在沙箱 iframe 里播放动画；降智记录同时显示判定原因与所用模型。
- 新增用户接口 `GET /channel-monitor-v2/quality-events` 与 `GET /channel-monitor-v2/quality-events/:id/artwork`，按当前用户可见分组鉴权，作品只允许读取本分组且已产生判定的记录。
- 视觉审核请求失败时记录真实上游错误；遇到 4xx（模型不收图片输入、请求体过大、模型不存在等重试无法自愈的情况）自动退回本地结构判定给出真实结论，不再让这些计划永远 inconclusive；5xx / 408 / 429 与网络错误仍保持 inconclusive，不会误伤调度。
