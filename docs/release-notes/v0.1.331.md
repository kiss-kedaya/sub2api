## 修复

- 修前：智能路由生视频按**入口第一组**计价，而该组实际不匹配。实例：组 43 / 账号 29131 / 720p 6 秒扣 USD 0.0756，正确组 25 单价 0.30/秒应为 1.8，差 1.7244。
  修后：创建时把**实际计费组**冻结到服务端快照。
- canvas 智能路由建 key 仅在明确操作时创建并去重。
- 分组用量汇总改用索引友好边界与一致快照。

## 风险与已知问题

- 无迁移、无余额/价格变更。**历史少扣未追补。**

- 旧版本 handler 会忽略新快照组，**混跑阶段仍可能扣错组**；1% 灰度不等于全局计费正确。
