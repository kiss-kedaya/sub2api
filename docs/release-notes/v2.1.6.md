# v2.1.6

工程向发版，网关行为与 v2.1.5 完全一致，无新增功能、无行为变更。

- 修掉 main 上连续多个 commit 的 CI 红灯（`golangci-lint` 与 `test` 两个 job）。这些失败从 `f12249dbd` 起就存在，与 v2.1.4/v2.1.5 的内容无关，但会淹没真正的新问题：
  - 测试里三处 `x.(T)` 单值类型断言改成 comma-ok 形式（lint 开了 `check-type-assertions`，单值断言失败是 panic 而非可读报错）。
  - 删掉 `http2.GoAwayError` 的类型匹配 —— x/net 已将其标为 deprecated，而该类型 `Error()` 的输出就是 `"http2: server sent GOAWAY and closed the connection; ..."`，函数中已有的字符串匹配分支覆盖同一情形，类型匹配是冗余的。
  - 删掉 `cline.go` 中三个从未接线的函数（`clineWalletRateLimitKey` / `isOfficialClineHost` / `clineAccountAPISupported`）及只被它们引用的常量。Cline 平台本身（`IsCline`、`PlatformCline` 注册、测试模型常量）保持不变。
  - API 契约测试的 `default_platform_quotas` 期望值补上 `cline` 与 `command_code`：生产端按 `AllowedQuotaPlatforms` 返回全部允许平台，这两个平台早已在该列表中，属于夹具未同步。

无新增数据库迁移。余额预扣 hold 仍默认关，生产 `DATABASE_MIGRATION_MODE` 保持 `validate`。二进制可回滚到 2.1.5（两者运行时行为等价）。
