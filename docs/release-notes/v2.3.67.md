# Sub2API 2.3.67

## newapi 上游余额恢复显示

- `unlimited_quota` 是**令牌**维度的开关，new-api 给每个用户自动创建的默认令牌都强制为 true，导致账户余额被「无限」挡住。
- 令牌 unlimited 但响应带 `user_quota` 时，改用账户额度做余额：`remaining = user_quota.total_available`。
- 令牌 unlimited 且没有 `user_quota`（老令牌 `allow_user_quota_query` 迁移后为 false）时，回退到 `/v1/dashboard/billing/subscription` + `/v1/dashboard/billing/usage` 取账户额度，`remaining = hard_limit_usd − total_usage/100`。
- `hard_limit_usd = 1e8` 是 unlimited 标记，不当余额使用。
- 读到余额后探测状态置为 ok，不再停在 unsupported。

## 网关 IP 风控：只禁用共用的 key，不封 IP

- 多个用户共用一个梯子导致出口 IP 相同是常态，封 IP 会把他们全部切断。地址拦截只保留人工手写的那份，不再自动追加。
- 命中后只禁用被共用的 key，并在用户 key 列表给出轮换入口，提示「此 key 可能被盗用，已暂停。轮换后可继续用」。
- 判定口径固定为**不同用户**：同一用户持有多把 key 时 `distinct_users` 恒为 1，永不命中。
- `key_disable_enabled` 单独打开即可生效，不再要求同时打开 `auto_add_enabled`。

## 后台自动条目显示账号

- 自动条目记录 `users [{id,email}]`，面板显示「涉及 N 个用户: 邮箱/#id」，key 总数降到上下文一行。
