# 2.3.106

## 性能

- **`/api/v1/auth/me` 复用窗口（PR #404）**：该接口是线上最忙的 API（近 15 分钟占全部 API 请求 26.3%）。后端增加 5 秒进程内 TTL 复用（键为用户 ID），前端 `refreshUser()` 增加 5 秒窗口与并发单飞、轮询 60s→90s、标签页隐藏时不轮询；支付结果、支付页、兑换、充值、资料保存、推广提现 6 处改为 `{ force: true }` 强制刷新。开关 `AUTH_ME_CACHE_DISABLED=true` 可随时关闭复用。

## 计费

- **强制 1h 缓存按 1h 单价计费（PR #406）**：密钥级强制 `cache_control.ttl=1h` 时，若上游回包缺少 `ephemeral_1h_input_tokens` 明细，旧逻辑按 5m 单价兜底，1h 单价更高会少收。现在按我们向上游声明的 TTL 计费：声明 1h 就用 1h 单价；上游给了明细仍以明细为准；inherit/off/5m 保持旧行为不变。

## 无迁移、无破坏性变更

- 数据库无迁移；接口字段无改动；计费只影响「强制 1h 且上游无明细」这一种组合。
