# Sub2API 2.3.58

## 性能：用量统计加缓存，Redis 压力下降

- 仪表盘/用量统计的聚合查询（`COUNT(*) + SUM(tokens)`、活跃用户、按天汇总等）加入 60 秒缓存，键为 `stats:usage:<sha256>`，哈希包含用户/密钥/账号/分组/模型/来源/时区/时间范围与全部过滤条件。
- 缓存不可用（Redis 断开、超时、解析失败）时**直接回落查库**，不影响接口可用性；写入不失效缓存，统计最多滞后 60 秒。
- IP 共用检测从每请求 6 条 Redis 命令降到 **1 次 Lua 往返**：同窗口内只写一次，热路径只做 `ZSCORE + ZCOUNT`。判定语义不变（5 分钟窗口、按不同用户计数、机房 IP、key ≥30 天）。

## 上游余额识别修复

- `/v1/dashboard/billing/subscription` 返回 `hard_limit_usd ≥ 1e8` 视为 new-api 的「无限」哨兵值，直接判定为 **new-api**，不再误判成「OpenAI 账单」。
- 识别为 new-api 后余额走 `/api/usage/token/`（同源 302 跟随），拿不到时显示「余额未提供 + 已用金额」，不再假报「无限额度」。
- 旧数据不再停更：`unsupported` 状态固定按 10 分钟继续探测。
- 「上游余额」列的刷新按钮改为 `type="button"`，点击不再整页刷新。

## 配置

- 新增 `usage_stats_cache.enabled`（默认 true）与 `usage_stats_cache.ttl`（默认 60s）。
