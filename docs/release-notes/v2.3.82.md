# 2.3.82

## 修复

- **Antigravity User-Agent 补 `/hub` 段**：与官方客户端一致（`antigravity/hub/<版本> windows/amd64`），恢复 Gemini 4 系列模型拉取（#331 / issue #330）。
- **注册页字段不再被禁用**：未勾选条款时只禁用提交按钮，邮箱、密码、邀请码输入框保持可编辑（#329 / issue #328）。
- **Crypto 归集 RPC 黑名单**：整个 `48.club` 域名拒绝，配置、自动发现、热重载三条路径统一过滤（#349）。

## 优化

- **连接轨迹清理提速**：`request_connection_traces` 保留期 30 天 → **14 天**；每轮从删 1 万行提升到 20 万行 × 最多 20 轮，执行超时 5s → 5min。原来每小时删 1 万行追不上每天几百万行的写入。
- **协议元数据不再落库**：`scheme`、`http_version`、`tls_version` 停止写入；`user_agent`、`method`、`host`、`upstream_status`、`network_error` 保留（#350）。

## 运维

- 全部网关单元加 `GOMEMLIMIT=16GiB`，压在 systemd `MemoryMax=20G` 之下，避免内核反复回收造成 RSS 锯齿与 OOM 风险。
- 全部网关单元 `TimeoutStopSec=120min`。
