# 2.3.150

## 安全收口：at-rest 加密默认关闭（防复发）

- 2026-11-22 的两次全站 502 都源于「上游凭据加密后网关读不到 api_key」。本版把 at-rest 加密改为**默认关闭**：
  - 新增总开关 `SUB2API_ATREST_ENABLED`，默认 `false`；仅配置密钥不再自动加密。
  - 关闭时写入只写明文、`credentials_cipher` / `password_cipher` 保持 NULL；读路径改成**明文优先**，历史 `enc:v2:` 行只有显式开启且密钥有效时才解密，缺密钥仍 fail-closed（绝不把密文当业务值）。
  - 开关显式为 true 但密钥缺失/无效时启动失败，不静默降级。
  - 代码与文档标注：开启前必须先跑真实网关请求验收（引用 2026-11-22 事故）。
- 迁移 `334` 的密文列为纯增量，无需回滚数据库。

## 充值：临时入账 / 已回滚状态全链路展示 + 扣回负向流水

- 扣回（reorg / revert / 替换）时，除扣减余额外**补一条用户可见的负向流水**：`type=crypto_revoke`、金额为负、原因「链上充值未最终确认已回滚」、来源关联 `crypto_deposit:<id>:<chain>:<tx>:<log>`；幂等（同一笔只写一次），卡密管理/导出/搜索自动排除这类流水。
- 管理端到账记录：新增「临时入账 / 已回滚」徽标、回滚原因、最终确认时间列，汇总卡增加临时与回滚计数。
- 用户充值记录：显示「临时入账 / 已回滚」及原因，并提示「该笔转账未被最终确认，如已扣款请联系客服」。
- 用户余额明细与后台余额弹窗：显示负向调整及来源；余额页对负余额给出明确说明（仍允许余额为负，不引入欠款台账）。
