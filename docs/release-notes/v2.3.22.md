# Sub2API 2.3.22

上线前的安全与稳定性收口。

## 安全

- 分组模型白名单：请求体归一化后再校验，修复 UTF-8 BOM 可绕过准入的问题。
- 「退出所有设备」现在会立即吊销已签发的 access token，而不只是 refresh token。
- 发验证码接口不再区分邮箱是否已注册，关闭账号枚举入口。
- 邮箱验证码校验改为原子操作，并发请求无法绕过尝试次数上限。

## 支付

- 退款按比例回收邀请返利，写 `refund_reversal` 流水，重复退款幂等。
- 退款失败重试绑定原扣款金额，金额不一致直接拒绝，避免多退。

## 性能与运维

- 过期订单清理每轮限制 200 条，避免外部状态查询风暴。
- 充值地址只为实际扫描的链分配，未启用的地址族不再返回。
- 退役 2.3.16–2.3.20 残留实例，生产仅保留 2.3.21 两个活跃实例。
