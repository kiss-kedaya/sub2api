# Sub2API 2.3.60

## 同 IP 风控：记录峰值与累计 Key 数

- 自动条目新增 `first_seen_users`（首次踩线时的人数，冻结）、`peak_users`（同一窗口内峰值）、`total_keys`（该 IP 24 小时内调用过的**不同 Key** 数）、`last_seen_at`。
- 同一窗口内后续命中会刷新峰值与累计值（写库节流：每个 IP 每 30 秒最多一次），不再只保留首次快照。
- 24 小时计数与 5 分钟判定窗口解耦：判定仍按 5 分钟不同用户数，累计按键统计。
- 旧条目缺字段时按 `distinct_users` / `key_prefixes` 回填，不影响读取与展示。

## 排除共享出口

- 来源 IP 落在 **Cloudflare 官方网段**或私有网段（10/8、172.16/12、192.168/16、127/8）时，不计数、不入列表、不停用 Key；CF 网段内置官方快照并每日刷新，刷新失败保留当前集合。

## Key 年龄

- 仍要求涉及的 Key 创建满 30 天；过新的 Key 在计数前排除并记录数量。

## 其他

- 修复自动条目合并逻辑在值接收者上原地修改、导致「峰值/累计永不落库」的缺陷。
- 后台自动条目区展示「首次 / 峰值 / 累计 Key / 最近时间」。
