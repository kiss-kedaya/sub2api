# Sub2API 2.3.55

## 登录 / 注册：Quiet 风格

- 卡片改成参考页的形态：`rounded-2xl` + `overflow-hidden` + `shadow-md`，宽 360、内边距 20，深浅色都成立。
- 输入框统一 `h-10`、`rounded-[10px]`，聚焦有独立阴影；按钮统一胶囊，`active:scale-[0.97]`。
- 注册改成三步分步（账号 / 邀请与优惠 / 校验与协议），带「第 N 步 共 M 步」与点状进度，底部 上一步/继续 固定。

## 账号列表

- 「上游声明倍率」直接显示数字（如 `0.60x`），不再显示「同账号倍率」这行字；与「账号倍率」列可直接对照。
- 定时开关的详情移进模态框：表格里只留一个 24×24 闹钟图标（有计划为着色态、无计划为中性描边），点开分「计划 / 执行记录」两页。表格不再因执行记录被撑宽、滚动不再抖动。

## 用量

- 修复「缓存明细」浮层被统计条 `overflow-hidden` 裁掉的问题：圆角改由背景与 ring 承担，浮层改为右对齐触发点，窄屏不再越界。

## 其他

- 发版流程补充：新二进制启动前会校验迁移，上线必须先 `-migrate-only` 再启动服务。
