### 上线步骤（蓝绿 + 1% 金丝雀）

1. 从 GitHub Release 下载本版二进制与 `checksums.txt`，`sha256sum -c checksums.txt` 通过后再用。
2. 先只读校验迁移：`./sub2api -check-migrations`；需要单独执行时 `./sub2api -migrate-only`（先做完整数据备份）。
3. 新端口另起一个 unit（旧实例不动），`curl -fsS http://127.0.0.1:<新端口>/` 必须是 `200 text/html`。
4. nginx upstream 指向新端口、`weight=1`（1% 金丝雀），`nginx -t` 通过后 reload。
5. 观察错误率、延迟与 panic 日志，无异常再放量到全量，旧实例留到新版本稳定。
