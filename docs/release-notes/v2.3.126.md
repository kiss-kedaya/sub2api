## 安全

- 2FA 校验按账号 60 秒滚动窗口限速 5 次（后端 Redis 滑动窗口 + 前端倒计时禁用），超限 429 `TWO_FACTOR_RATE_LIMITED`，限速存储故障时 fail-closed。
- 审计日志禁止通过后台清理（固定 403，只能数据库层清理），审计保留期调整为 90 天。
- 支付渠道配置落库加密（AES-256-GCM，`v2:` 前缀，历史明文惰性迁移，解密失败 fail-closed）。
- 加密签名审计补操作者归属（用户/邮箱/IP/UA/request_id/auth_method），助记词与私钥导出可追溯到人。
- 充值地址轮换能力：单事务轮换到池内新地址，旧行保留 disabled 供扫描器继续监控。
- 前端依赖升级 vue-i18n 11 / @intlify 11，移除到期的 GHSA-83rm-6c8r-g728 豁免。
