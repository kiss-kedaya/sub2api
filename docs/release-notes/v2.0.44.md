## 分组协议与原生转发

- 创建和编辑所有平台分组时均显示跨协议转换开关。新分组默认关闭，编辑时正确读取和保存已有值。
- 参考 cc-switch 的协议选择方式：有原生 Messages 端点的自适应账号优先直通；显式 Chat/Responses 配置及 Codex OAuth 的协议约束继续生效。
- 未配置原生 Messages 端点的自适应账号不再进入无效原生路径；跨协议转换仍受分组开关控制。
- 修复原生地址带 `/v1` 时重复拼接路径，以及原生请求被错误记录为 Chat Completions 上游的问题。

## 使用记录秒级筛选

- 管理员使用记录筛选区可选择完整日期、时、分、秒，支持快捷范围和自定义范围。
- 用量明细、统计、图表、用户排行、错误记录及导出使用同一时间范围。结束时间包含所选的完整一秒，保留旧日期参数兼容性。
- 精确范围不再被旧按小时/天汇总扩大；清理确认保留选中的时间边界，导出文件名兼容 Windows。

本版无新增数据库迁移，不改价格和预扣配置。
