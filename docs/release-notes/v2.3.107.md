# 2.3.107

## 计费

- **强制 1h 缓存按 1h 单价计费（PR #406）**：密钥级强制 `cache_control.ttl=1h` 时，若上游回包缺少 `ephemeral_1h_input_tokens` 明细，旧逻辑按 5m 单价兜底。1h 单价高于 5m，这种组合会少收。现在按我们向上游声明的 TTL 计费：声明 1h 就用 1h 单价；上游给了明细仍以明细为准；inherit / off / 5m 三种模式行为不变。

## 说明

- 数据库无迁移；接口字段无改动；只影响「密钥强制 1h 且上游无 ephemeral 明细」这一种组合。
- 包含上一版 2.3.106 的全部内容（`/api/v1/auth/me` 5 秒复用与前端去重等）。
