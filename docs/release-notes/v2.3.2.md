# Sub2API 2.3.2

## 修复

- 修复管理员登录 2FA：验证码只有在登录、会话和 OAuth 绑定检查全部通过后才会消费。
- 修复首次请求因下游会话检查失败后，重试同一有效验证码被误报为“验证码已使用”。
- 保留支付、敏感操作和 step-up 场景的一次性验证码消费与防重放语义。
- 更新 `golang.org/x/crypto` 到包含 GO-2026-5932 修复的版本。
- 修复 Release workflow 中残留的合并冲突标记，恢复官方 Go/SSR 制品发布链路。

## 验证

- GitHub Actions CI、Go 全量测试、前端构建、SSR 认证页面、敏感信息扫描和安全扫描。
- 不涉及数据库迁移，生产环境保持 `DATABASE_MIGRATION_MODE=validate`。
- 发布使用 GitHub Actions 官方 Go 与 Nuxt SSR 制品，不使用本地构建产物。

## 回滚

保留上一版 Go/SSR 制品与旧 upstream；若任一真实页面、API JSON 或登录链路验收失败，先回切旧版本，不覆盖当前运行目录。
