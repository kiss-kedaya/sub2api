# 2.3.91

## 紧急修复

- **渠道定价保存报错**：2.3.90 加 `ultrafast_multiplier` 列时，INSERT 的列清单有 17 项但 `VALUES` 只补到 `$16`，PostgreSQL 报 `INSERT has more target columns than expressions`，导致后台保存渠道定价**全部失败**。现已补齐 `$17`。

## 防回归

- 新增 `TestChannelModelPricingSQLColumnPlaceholderParity`：直接读取源码中的 INSERT/UPDATE 语句，比对列数与占位符数。原有 sqlmock 测试按位置传参、不校验二者数量，正是这次漏网的原因。
