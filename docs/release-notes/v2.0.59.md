# v2.0.59

- 账号池权限改用服务端配置的稳定用户 ID，不再按邮箱判断；改邮箱不再影响管理员可见范围。
- 账号池隔离改为**可选开启**：未配置 `security.account_pool_owner_user_id` 时所有管理员照常可见全部账号，不会因升级丢失历史账号（`created_by` 为空的老账号）。
- 堵住账号越权路径：按 ID 删除/清错/切调度、批量绑组、读统计缓存、CRS 同步、Grok 配额探测在写入前先校验归属。
- 限制非主管理员生成全局管理密钥、修改主管理员资料或绑定外部登录身份。
- 分页上限由后端执行，导出与选择器按真实页长读取；优先级统一为大于等于 0 的整数。
- 管理员并发/优先级/RPM 与分组限额拒绝负数与非有限值，直接用接口也会被拦。
- 支付服务商写接口不再回传加密配置；订单列表支持精确到秒的时间区间。
- 返利配置改为单事务提交，批量更新回报数据库实际影响行数。
- 网关拒绝请求体中重复的顶层 `model` 字段，避免出站模型与计费模型不一致。
- 易支付通知只接受真实异步回调参数集，拒绝未知字段，防止下单签名被重放为成功通知。
- 新装环境不再使用可猜的管理员账号：`ADMIN_EMAIL` 为空时生成随机邮箱，用户提供的邮箱与密码按登录口径校验（密码 8–72 字节）。
- API Key 在请求进行中被删除时仍结算用户余额与订阅，不再整体回滚计费事务。
- 前端依赖升级 vue `^3.5.43`、`source-map-js >= 1.2.2`，修复安全审计项。
- 分页查询参数只接受纯数字，`-1`、`1 2` 等一律拒绝。
- 新增安全策略文档与私密漏洞报告入口。

无新增数据库迁移。沿用滚动发布，保留旧版回滚文件。
