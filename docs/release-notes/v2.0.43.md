## thinking.display = updates

- 客户端在请求里写了 `thinking.display: "updates"` 时，网关自动补上 `anthropic-beta: thinking-display-updates-2026-08-18`。此前缺这个头，上游直接 400：`thinking.display: Input should be 'summarized', 'omitted'`。
- 只在请求声明了 `updates` 时补；客户端已经带了就不重复；其余请求的请求头一个字节不变。

## 分组级跨协议转换开关

- 分组编辑页新增「允许跨协议转换」。只管 Anthropic（`/v1/messages`）与 OpenAI（`/v1/responses`、`/v1/chat/completions`）两族之间的互转；OpenAI 族内部 chat ↔ responses 不受影响。
- 关闭时返回明确的 `400 cross_protocol_conversion_disabled`，不再静默转换。
- **升级后所有已有分组保持开启，行为与升级前一致**；新建分组默认关闭。要收紧就在后台逐个分组关。

## API 密钥：Anthropic 缓存 TTL

- 密钥页新增「Anthropic 缓存 TTL」：跟随全局 / 关闭 / 强制 1 小时 / 强制 5 分钟。密钥级设置优先于管理员全局开关，两者互不写回。只对打到 Anthropic 上游的请求生效。

## 后台设置：两套预扣费分开开关

- 设置页可分别开关「入口余额预扣」与「在途预留」，默认都关；两套同时开会把同一份余额算两遍。未配置时沿用部署配置，存量环境行为不变。

## 错误日志：请求头 / 响应头

- 每条错误记录可看三份头：客户端→网关、网关→上游、上游→网关。授权、密钥、Cookie 类头整条不记。
