# 2.3.97

## 新功能

- **DeepSeek 语音识别、语音合成、文档识别接口**：DeepSeek 分组的密钥可以直接调用
  `POST /v1/tools/asr`（语音转文字）、`POST /v1/tools/tts`（文字转语音，音频边合成边返回）、
  `POST /v1/tools/ocr`（PDF / Word / PowerPoint / 图片识别），请求和响应与 DeepSeek 官方一致。
  暂不支持 WebSocket 流式合成。
- **按量计费，分组可单独定价**（和独立搜索一样是固定工具价，不乘分组倍率）：
  - 语音识别按音频时长计，向上取整到秒；默认 0.78 / 小时。
  - 语音合成按请求文本的计费字符计（汉字算 2 个，其余算 1 个）；默认 3 / 万字符。
  - 文档识别按识别成功的页数计；默认 1.5 / 千页。
  - 后台分组编辑页（DeepSeek 分组）新增三个价格输入框：留空用默认价，填 0 免费。
  - 上游报错、识别失败、合成中途断流都不计费；文件上传完成后客户端断开，识别仍会完成并计费
   （与官方规则一致）。
- **文档页**（/docs）新增「语音识别 ASR」「语音合成 TTS」「文档识别 OCR」三页，含参数、示例、
  错误和计费说明。

## 调整

- 独立搜索 / 抓取接口在整组账号都忙时返回并发繁忙提示，不再返回笼统的上游错误。
