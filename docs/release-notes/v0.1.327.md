## 新功能

- API Key 编辑器改为按提供商分组选择；空提供商禁用，清理过期的单组选择，保留跨提供商的有序智能路由。

## 修复

- 修前：智能路由选号后，计费/订阅/预留/转发策略仍绑在**入口组**，快照选号会退化成反复扫账号表。
  修后：绑定到**实际选中的路由**，快照选号不再回扫数据库。
- Gemini bridge 按配置协议转发，保留独占普通/缓存输入用量、部分用量、取消与终态错误。
- 补齐候选的 Messages 分发权限、候选模型上下文、订阅资格绑定。

## 风险与已知问题

- 无迁移、无余额/价格/倍率变更。
- 发布前 CI 发现一条 WebSocket 抢占测试的顺序竞态，**只改了测试**，未动运行时代码。
- `gpt-5.5` / `gpt-5.6-sol` 上游 overload，未解决。

## 升级注意

- 回退时保留各入口自身配置作基线，不要用统一目标。
- 退出旧进程只限「nginx 已无引用 + 两次采样零连接」。
