# 2.3.119

## 原样透传（重点）

- **新增「请求整流器 → Anthropic thinking 改写」开关，默认关闭**。关闭时 Anthropic 请求体（`thinking` 字段）在所有出站路径上一个字节都不改，行为与直连上游完全一致：官方/上游该返回 400 的参数组合（5.5 代模型的 `thinking.type=disabled`、`enabled+budget_tokens`、`disabled+xhigh` 等）原样返回 400，不再被网关悄悄改写成合法请求。
- 打开开关才恢复此前的兼容改写（`disabled`→省略 thinking、`enabled`→`adaptive` 并删 `budget_tokens`、`between_tools` 视型号改写）。
- 背景：此前这层改写会让 5.5 代模型「关思考」的请求被上游按 adaptive 执行并计 thinking token，用户多付钱；透传分组也无法与上游直连行为对齐。

## 同期已合并的功能（本版一并包含）

- Claude Fable 5.2 / Mythos 5.2 目录与计费（$8/$40，修正此前按 5.0/5.1 的 $10/$50 多收）
- Gemini 4 Argon 目录、映射与兜底计费（Cyber 变体单列）
- `gateway.min_output_tokens`、`gateway.max_same_account_retries_gemini` 可配置
- GPT-6.2 Sol / Astra 模型与官方计费
- 上游 503「请求体缓冲耗尽」不再同号重试，保留 503 并透传 `Retry-After`
- OpenAI 缓存写入 12h 价（迁移 321）、Vertex 账号接入通用配额、管理员 API Key 分权（迁移 322）、生图账号 1K/2K/4K 尺寸档位分流

## 说明

- 数据库迁移：321（OpenAI 12h 缓存写入价）、322（管理员 API Key 分权），均可空/新建，无回填。
- 默认行为变化仅一项：thinking 不再被改写；需要旧兼容行为时在后台「请求整流器」打开开关即可。
