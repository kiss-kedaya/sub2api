# Sub2API 2.3.62

## 充值到账说明修正（原生币按市价结算）

- 原生币（ETH / BNB）不再显示「1 ETH = 6.7 余额单位」这种固定单价，改为「**结算方式：按到账时刻市价结算**」；能取到行情时附一行「当前约 $X / 枚，仅供参考」。
- 稳定币（USDT / USDC）保持原口径「1 USDT = N 余额单位」。
- 最小入账金额与单笔上限改为按**美元名义价值**标注（`0.001 USD` / `10000 USD`），与后端实际判定口径一致——原来界面把 USD 参数当成币数量显示，单位与数字都不对。

## 接口

- `GET /api/v1/crypto/deposit-info`：`assets[]` 新增 `market_priced`、`rate`（原生币为 null）、可选 `reference_price_usd`；响应级 `rate` 移除。前端对旧后端保留回退，滚动发布不空行。

## 其他

- 测试夹具里的真实生产 IP 换成 RFC 5737 文档保留地址，避免把客户地址提交进仓库。
