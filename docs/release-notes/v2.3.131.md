# 2.3.131

## 安全（本版重点）

- **API Key 只存 SHA-256 哈希**：新增 `api_key_hashes` 台账与 `api_keys.key_hash` 索引，创建/轮换只写哈希与前缀，明文仅在创建/轮换响应返回一次；鉴权改为哈希等值查询，过渡期保留明文回退；`api_keys.key` 改为可空，回填完成后清理明文（64,442 行）。
- 顺修复 durable 认证缓存失效触发器：改为按 `key_hash` 失效，新行无明文也能跨实例失效。
- 钱包安全守卫暂停只触发一次（`crypto.security.pause.v1` 标记），管理员开启加密通道不再被同一锁事件每分钟冲掉；钱包锁定时后台「关→开」返回 409 `CRYPTO_WALLET_SECURITY_LOCKED`。
- 管理端兑换码、优惠码、渠道密钥、上游额度、订阅权益、公告发布等写操作补齐 step-up 2FA。

## 其他

- 自定义 API Key 拒绝明显可预测的取值。
- 无新增数据库迁移（本次发版包含 327_api_key_hash_storage.sql，需 `-migrate-only` 应用）。

## 上线后运维步骤（按顺序）

1. `-check-migrations` → `-migrate-only` 应用 327。
2. 回填 `key_hash`/`key_prefix` 与新表（分批），校验全 0。
3. 抽查真实 key 鉴权 200。
4. 清理 `api_keys.key` 明文（写入 NULL，不能写空串）。
5. 回滚只需按备份表还原明文列。
