# v2.2.32

## 定价

- 修正 Claude Sonnet 5.5 的缓存读取基础价为每百万 Token 0.10 美元，覆盖远程价格目录与本地回退路径；保留显式自定义价格覆盖。

## 余额同步

- 提高实时钱包 outbox 的批量领取能力，并按用户连续事件前缀批量写入 Redis，单个用户每轮最多推进 256 条。
- 每批使用同一原子 Lua 脚本维护余额与水位；数据库批量确认失败时，重放仍由水位幂等保护。
- 失败重试仍按原有指数退避；不跳过失败事件，不把不连续的账本事件合并，也不绕过在途结算检查。
- 保持 PostgreSQL 部署配置及预扣开关不变。

## 在途请求

- 优化展开面板的布局、请求数量、刷新和加载状态；管理员可直接看到账户与分组。
- 在途元数据跟随实际换号、换组更新，不为显示名称增加请求热路径数据库查询；普通用户与观察者继续遵循原有脱敏规则。

## 用户并发

- 修复用户最大并发设为 0 后被归一为 1 的问题，0 正确表示不限用户并发。
- 不限并发仍记录实际在途数量，切回正数时继续计入原有请求；API Key 与上游账号的独立限额保持生效。
