# v2.3.163

本次为「首屏加载」小版本：首次打开页面更快、慢网络下页面不再一片空白、连续圆角补齐第二轮。无数据库迁移，不改后端接口，扫链代码无改动。

## 亮点

- **首次打开更快**（#626、#627）：以前浏览器要先下载入口脚本，再下载语言包，等语言包下完才开始下载第一个页面的代码——两个独立的下载排成了一条队，慢网络下各多等一个来回；同时每位访客打开任何页面（包括登录页）都要先下载一个约 1.55 MB（未压缩）的共享包，里面大半是只有少数页面才用的第三方库（二维码、签名分片、拖拽……）。现在语言包和第一个页面的代码同时下载，共享包只保留首屏用得到的部分（约 0.97 MB），其余库跟着用到它们的页面按需加载。登录页冷加载、表单进入页面的时间（本地生产构建 + 浏览器冷缓存，7 次中位数）：慢网（RTT 400 ms / 3 Mbps）4218 → 3408 ms（−19%），中速（RTT 150 ms / 9 Mbps）1633 → 1335 ms（−18%），快网（RTT 40 ms / 50 Mbps）577 → 423 ms（−27%）；登录页传输从 816 KB 降到 693 KB。**回访用户不受影响**：共享包的文件名哈希只随第三方依赖变化，发版后只需重新下载入口（约 320 KB 未压缩）。
- **慢网络下页面不再一片空白**（#626）：页面空白超过 0.4 秒时，顶部出现一条灰色细加载条，页面出来后自动消失；加载很快时不会出现；系统开了「减少动态效果」时只显示一条静态细线。标签页标题在语言包到位后再确定一次，首屏标题不再先显示英文再跳成中文。
- **连续圆角补齐第二轮**（#625）：把「所有圆角连续、丝滑」从用户页扩到管理后台 9 个页面和打开的叠层（命令面板、分组下拉、创建弹窗展开区、日期筛选），修掉 64 个仍是普通圆弧的元素（引导气泡及其键位提示、设置页的 tab 触发器等）；药丸和圆形保持圆形。

## 变更清单

### 优化

- 语言包与首个页面的代码并行下载、一起就绪后再挂载（#626）
- 空白超过 0.4 秒的纯 CSS 细加载条，`prefers-reduced-motion` 下只留静态底线（#626）
- `document.title` 收口到 `applyDocumentTitle()`：路由守卫、切换语言、App 外壳、启动流程共用，语言包到位后再算一次（#626）
- 第三方库的兜底分包只收纳入口静态可达的模块：`vendor-misc` 1.55 MB → 0.97 MB，`jsqr` 等只被懒加载页面用到的库跟着页面走（#627）

### 修复

- 管理后台页、引导气泡、tab 触发器上仍是普通圆弧的圆角（#625）

### 测试

- `indexHtml.spec.ts`（无内联脚本、`#app` 保持为空、每条动画 0.4 秒延迟、reduced-motion、不写死背景）、`documentTitle.spec.ts`、`bootChunks.spec.ts`（首屏可达性遍历）；对这三个 spec 做了变异检查，全部被发现（#626、#627）

## 升级与兼容说明

- **数据库迁移**：无。
- **页面刷新**：本版前端文件有变化，已打开的旧标签页会在几分钟内提示「发现新版本」。
- **缓存**：共享包 `vendor-misc` 等第三方包文件名不变，回访用户只需重下入口文件。
- **取舍**：首次访问用到这些库的页面（例如密钥页）会多取约 25 KB、多几个请求，慢网下多约 0.05–0.09 秒；把落地页加后续四个页面都点一遍，合计只快约 1%，收益主要给第一次打开网站的人和不点那些页面的人。
- **crypto 侧车**：本版没有改动扫链代码，侧车保持 2.3.155 即可，不必更换。
- **上线后仍需人工确认**（沿用 2.3.154）：`gateway_5xx` 告警规则被迁移 339 禁用后，需在后台按新口径重设阈值并重新启用。

## 已知问题（不阻塞本版，后续处理）

- 系统偏好为深色的访客，在页面加载完成前看到的仍是白底（原来就是这样，样式表里 `html { color-scheme: light }` 盖过了 `<meta name="color-scheme">`）。要彻底解决需要服务端把主题写进 HTML，不能在 CSS 里按系统偏好猜（站点默认模式、访客已保存的选择会与系统偏好不一致，反而闪错颜色）。
- 首屏必载文件里最大的是界面套件本体（reka-ui + Nuxt UI，约占共享包一半以上），业务代码拆不动；能再省的只有新手引导（driver.js）和公告 markdown 渲染（marked + dompurify）两处，合计压缩后约 30–40 KB，改成「用到才加载」有公告先空后出的风险，暂不做。
- 语言包要等入口脚本和 4 个共享包全部下载并执行完才开始下载。若由服务端按语言在 HTML 里预加载语言包，估计慢网下还可再省 0.4 秒左右（按瀑布估算，未经验证），需要改 Go 注入逻辑和构建清单，待决定。

## 部署

1. 从 Release 下载 `sub2api_2.3.163_linux_amd64.tar.gz` 与 `checksums.txt`，先 `sha256sum -c checksums.txt`。
2. 新二进制执行 `-check-migrations`（本版预期没有待执行迁移）。
3. 蓝绿部署：新端口启动新实例，`/health` 与首页 200 后先接 1% 流量，观察错误率与日志再放量；nginx 里写死 upstream 的路由族（固定池）要一起改指新端口。选新端口时用 `ss -tan` 查任意状态，别只看监听（出站连接的源端口可能恰好等于候选端口）。
4. 旧实例保留至新版本稳定，回滚只需把流量切回上一版端口。

## 验证清单

- 首页与 `/api/v1/settings/public` 版本号为 2.3.163，首页注入的 `window.__APP_CONFIG__.version` 也是 2.3.163，页面入口资源哈希与后端一致。
- 浏览器开发者工具 → Network，勾「Disable cache」并选「Slow 3G」，刷新登录页：约 0.4 秒后顶部出现一条灰色细条，页面出来后它消失；瀑布里语言包（`index-*.js`）与页面代码同一时刻发出，不再一个接一个；没有 `airwallex.com` 的请求。
- 登录页传输体积约 0.69 MB（改动前约 0.82 MB）；`dist/assets/vendor-misc-*.js` 约 970 KB。
- 切换界面语言，标签页标题跟着变；刷新后标题直接是目标语言。
- 打开管理后台设置页，tab 触发器的圆角是连续曲线；打开新手引导气泡，气泡和键位提示的圆角也是连续曲线；药丸按钮仍是圆的。
- 逐个打开用到二维码、签名分片、日期选择的页面，功能与上一版一致。
