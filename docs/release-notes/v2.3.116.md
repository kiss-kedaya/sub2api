# 2.3.116

## 安全修复（紧急）

- **拒绝请求体重复字段（GHSA-p3r4-jcm3-2hph）**：请求体（含嵌套字段、`session` 对象、multipart 字段）以及后续 WebSocket 帧中，同名字段重复且取值不一致时直接返回 400。此前同名字段会让 `gjson`（取第一个）与 `json.Unmarshal`（取最后一个）读到不同值，进而按低价模型计费、实际调用高价模型，并可绕过账号模型映射、OpenAI fast policy、分组强制 `service_tier`。
- 扫描器覆盖：大小写变体、转义写法、multipart 的 RFC 2231 扩展字段名；相同取值的重复字段仍放行。
- 所有网关链在分组模型白名单之后、合成路由改写之前挂载；命中按各入口协议格式返回 400，并记录 ingress 拒绝原因 `conflicting_request_fields`。

## 破坏性变更

- 重复声明且取值不同的同名字段从现在起返回 400。正常 SDK/客户端不受影响。

## 说明

- 本次只包含安全修复，无其他功能改动、无数据库迁移。
