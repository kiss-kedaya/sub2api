# Sub2API 2.3.70

## gas 补给不再被当成用户入账

- gas 钱包归集前给地址打 gas，扫链把它读成了用户的原生币入账：用户侧多出一条「未入账」的 BNB/ETH，同时也真的入过账。
- 扫链现在按「发送方 = 我方钱包（hot wallet + gas payer）」跳过 native 转账；ERC20 入账不受影响。
- 用户账单列表同步隐藏这类历史记录，修复前写进去的旧行也不会再显示。

## 运维提示

- `hot_wallet_evm` 与 gas 钱包地址必须是真正的自家钱包。若误配成用户地址，该用户的原生币入账会被当成自家转账跳过。
- 已入账的历史 gas 补给（约 0.00063 BNB，合计不足 1 美元）不回滚余额，仅从账单列表隐藏。
