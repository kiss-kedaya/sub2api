# Sub2API 2.3.65

## 止血：公开设置接口不再被登录页打爆

- `GET /api/v1/settings/public` 增加 `Cache-Control: public, max-age=30`。该接口公开只读、响应超过 100KB，此前无任何缓存头。
- 前端 `fetchPublicSettings` 失败后 30 秒内不再重试（`force=true` 仍可穿透，成功一次即清零冷却）。
- 背景：登录页在重定向时反复挂载，每次挂载重拉一次设置；被限流返回 429 后立刻重试，一度放大到每分钟 1,761 次请求、其中 76% 是 429，把机器 load 打到 42。

## 修复：message_delta 占位值不再清空已上报的输入 Token

- 上游在 `message_delta` 里给出 `input_tokens: 0` 这类占位值时，不再覆盖此前已经上报的输入 token 计数，避免用量被清零。

## 说明

- 无迁移。
- 设置项改动最多 30 秒后才对浏览器生效（后台改配置后强刷或等缓存过期）。
