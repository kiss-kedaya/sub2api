# v2.2.25

改进充值漏单恢复，并增加固定五分钟的管理员支付验证凭证。

## 充值扫描
- 补扫有限近期区块，恢复 RPC 日志延迟索引造成的漏单，保留回执、规范区块、最终性及去重检查。
- 为核验和对账设置等待边界，慢 RPC 不再无限阻塞新充值扫描。
- 未配置 RPC 时可发现并验证公开 Chainlist 节点，手工配置优先，保留 DNS、跳转和超时校验。

## 支付验证
- 新鲜 2FA 验证后签发固定五分钟凭证，绑定管理员、登录会话及当前安全状态。
- 拒绝伪造、过期、跨会话及已撤销凭证；敏感请求逐次复核授权，不重放结果不明的资金操作。
- 凭证仅驻留浏览器内存，审计日志脱敏相关请求头及验证正文。

## 升级注意
- 无新增数据库迁移。
