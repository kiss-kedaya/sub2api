# v2.1.10

网关错误语义修正：上游过载还原为官方 529，取消请求不再误记成上游错误；管理台模态框观感统一。

- 上游错误映射：错误体自述 `overloaded_error` 时按官方语义还原为 529（覆盖中转把过载改写成 500/502 的场景）；503 保持“暂时不可用”语义不变。
- failover 耗尽不再把上游 5xx（500/504/520 等）折叠成 502，上游状态码原样透出；仅保留 401/403 的凭证掩码。
- Anthropic API Key 直通流：上游流内错误事件视为本次请求的语义终态，照常透传后不再追加 502「Upstream request failed」兜底帧；ops 记录按官方语义归类（overloaded→529、限流→429）。
- 客户端断开：请求上下文已取消时按 499 归因并跳过 502 兜底写入，取消请求不再计入上游错误率。
- 前端：模态框统一站点玻璃拟态风格与过渡动效；清理已移除检测项的历史文案。

无新增数据库迁移。
