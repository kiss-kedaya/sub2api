# v2.2.41

定向适配诊断、运维与专项协议能力，保持现有计费、顺序路由、会话归属和管理员权限边界。

- 增加连接时间线、四段应用层报文采集、分组缓存测试与用户传输量统计。
- 增加独立、默认关闭的 ID1 持续诊断；只采集已鉴权 ID1，各条记录保留八小时，正文查看和导出继续强制主管理员 2FA，资源限制和省略原因可见。
- 增加账号定时调度、分通道通知及恢复送达、渠道运维、受管 Mihomo 与凭据巡检。
- 增加 Key 独立并发与等待队列；0 不增加 Key 限制，用户并发 0 仍表示不限。
- 增加 Gemini 显式缓存生命周期、账号绑定、存储费用与持久幂等结算恢复。
- 适配独立 Excel/BPS 授权、Copilot SDK、Seedance Ark 与 MiniMax-H3 异步视频；依赖对应提供商支持与授权，不内置公共凭据。
- 增加默认关闭的账号自动化、在线地区路由、可选邮箱别名策略及分层 API 限制；不接入离线鉴权或离线账本预览。
- 修复原生 DeepSeek 工具续轮的完整思考回传：只恢复上游确实返回且作用域匹配的数据，不伪造思考、不使用摘要替代、不关闭 thinking。
- 保留缓存接口的 429 状态，修正 503 协议标识和 TypeSafe 地址重复版本路径；更新存在已知 HTML 解析漏洞的依赖。
- 补齐历史已发布版本的源码说明，不把公开发布记录等同于生产部署证明。

升级注意：新增30个迁移文件（编号270至305含空号），需使用官方迁移工具，业务进程继续validate。大表并发索引应单独检查资源、锁和有效状态，避免固定短超时留下无效索引。新自动策略与专项通道默认不启用；仅部署二进制不代表已完成提供商端到端授权验收。采集必须配置每个蓝绿槽位的稳定身份，并固定管理入口；保留旧请求与采集保留期的清理所有权。
