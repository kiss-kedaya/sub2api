# Sub2API 2.3.27

## 安全与调度

- 上游渠道 API Key reveal 接口补 step-up。
- 池化 API Key 账号失败时正确释放会话槽（与注册逻辑对齐）。
- 多实例启动槽位清理改为 opt-in（`SUB2API_STARTUP_SLOT_CLEANUP=enabled`），默认不再清掉健康实例的并发槽。
- 首页 HTML 经 DOMPurify 消毒，iframe 增加 URL 校验与 sandbox。
- 边缘 nginx 增加 HSTS（随部署生效）。

## 归集与扫链

- 空 getLogs 结果先证明应答节点已同步到扫描区间，落后节点换端点，游标不再跳过区间。
- 归集确认优先 finalized/safe；新增最近 swept 行的周期性回执复核对账。
- 链/代币移除后的 pending 充值转 `dead_letter` 并告警，不再静默轮转。
- 多地址归集：预留/去重不再被当成存储故障中止整轮；gas 不足/付款方缺余额改为可重试等待，不再烧满 revision 或阻塞整条链；reconcile 不再复活已释放的 stale 任务。

## 工程卫生

- 安装脚本校验失败 fail-closed；`/etc/sub2api` 权限收紧。
- Docker 基础镜像统一到受支持的 alpine 版本；release workflow 的 DockerHub 步骤按凭据探测跳过。
