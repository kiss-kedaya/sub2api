# 2.3.135

## 支付

- EasyPay 兼容网关回调解析改为「宽容解析 + 签名覆盖全部参数」：不再因 `bill_trade_no`、`api_trade_no`、`buyer` 等支付方生成的变体字段返回 400；同时保留 #7881 参数夹带重放防线（拒绝下单请求载体字段、拒绝值内嵌参数对、必需字段唯一、金额非法拒绝）。
- 新增设置项 `payment.easypay.skip_upstream_verify`（默认关闭）：部分服务商不提供订单查询接口或查单域名不可达时，允许凭已验签回调直接入账；通知签名、回调金额与订单金额、订单归属、已完成状态判断全部保留。

## 安全 / 数据

- API Key 哈希化后的软删除行清理：已软删除行不再保留 `key_hash`（此前回填误写入，已清 0）。
- 第三方身份 subject 改为 HMAC keyed hash + 盲索引（迁移 329，已在 2.3.134 起随版本应用）。
- 卡密哈希化结构（迁移 328），阶段 B 回填与清明文待后续执行。
