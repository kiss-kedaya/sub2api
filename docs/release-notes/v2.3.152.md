# 2.3.152

## 修复：管理端「测试账号/模型」不再要求 2FA

- **问题**：管理端「测试设置」里逐模型测试、测试全部，每个请求都返回 `HTTP 403 This operation requires recent two-factor verification`。
- **原因**：测试接口 `POST /api/v1/admin/accounts/:id/test` 挂在「账号写操作」前缀规则下，因是 POST 被统一归为 step-up，而该接口只返回模型连通性与耗时，不返回任何上游凭据。
- **修复**：在 `adminroutepolicy` 里把该接口精确归类为 secret-free（新增原因码 `account_connectivity_test_no_secret`）。
- **边界不变**：上游凭据回读 `GET /accounts/:id/credential`、整表导出 `GET /accounts/data`、账号创建/编辑/删除/批量操作仍然要求 step-up；机器凭据依旧不能调用 secret-free 路由。
- 路由覆盖矩阵仍完整（641 条无未归类）。

## 说明

- 无数据库迁移，前端无需改动（策略为编译期常量，需重新构建二进制）。
- 回滚：切回 2.3.151。
