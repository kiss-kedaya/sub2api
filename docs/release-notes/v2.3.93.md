# 2.3.93

## 新功能

- **导出拆成 CSV / Excel 两个入口**：此前只有一个按钮，文案写「导出 CSV」实际产出 xlsx。CSV 带 UTF-8 BOM，Excel 打开中文不乱码；两种格式复用同一次分页采集，不会为 CSV 再打一遍用量接口。
- **分组使用分布保留已删除分组的用量**：分组被删后历史用量不再从图表里消失，按「已删除分组 #<id>」显示并加灰/删除线/「已删除」徽标，请求数、token、成本全部保留 —— 这样页面上各行之和才能对上真实总量。

## 修复

- **纠正 2.3.92 的音频定价越界**：`defaultAudioTTSPricePerMillionChars` / `defaultAudioSTTPricePerHour` 服务的是 xAI Grok 语音（`/v1/tts`、`/v1/stt`），不是 DeepSeek。2.3.92 把它们改成了 DeepSeek 官方价，等于把 xAI 语音抬到 20 倍 / 7.8 倍。现已恢复 15.0 / 0.10；DeepSeek 的 OCR 默认价（1.5/千页）保留。

  影响面：近 7 天无音频计费行（`billing_type` 只有 0），2.3.92 上线期间没有实际多扣。
