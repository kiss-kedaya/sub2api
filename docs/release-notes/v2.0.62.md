# v2.0.62

- 继续修复 Grok 视频下载：第三方中转在任务状态里把 `video.url` 写成自家 CDN 直链（`https://cdn.<中转域名>/m/<id>`），既不是 xAI 官方签名直链，也不是中转自己的 `/videos/<task>/content`。网关此前把这类 URL 当成解析错误直接抛出，最终对用户返回 `502 Upstream request failed`，即使视频已经生成完成也拿不到内容。
- 改为：只有校验通过的 xAI 官方签名直链（`vidgen.x.ai`，https + 443 端口）才直接取用；其它由上游给出的 URL 一律不落地请求，回退到带鉴权的中转 content 端点，由它 302 到 CDN，并继续按每一跳做公网地址校验。
- 行为差异：以前遇到无法识别的 `video.url` 会直接失败并报 502；现在改为回退取视频。上游可控 URL 依旧不会被带着账号凭据请求——云元数据地址、伪装域名等仍然取不到任何东西（测试中已断言这些 URL 一次都不会出现在实际请求里）。
- v2.0.61 引入的中转 302 跟随逻辑保持有效，本次是同一问题链上的第二段修复。

无新增数据库迁移。沿用滚动发布，保留旧版回滚文件。
