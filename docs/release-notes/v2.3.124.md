# 2.3.124

## 安全修复（本版重点）

- **管理面会话撤销生效**：`/api/v1/admin/*` 与管理 WS 通道补齐 `auth:revoked_before` 校验，「撤销所有会话」后被撤销的管理员 access token 立即 401。
- **2FA fail-closed**：密码登录、pending OAuth「绑定已有账户登录」改用 `LoginRequiresTOTP`，设置读取失败按「需要验证」处理。
- **OAuth 注册策略一致化**：GitHub/Google/OIDC/钉钉注册路径补齐邮箱别名/域名黑名单，堵住 `registration_email_alias_block_enabled` 绕过。
- **refresh token 复用撤销整族**：已消费 token 重放即撤销 token family，返回 401 `REFRESH_TOKEN_REUSE`。
- **TOTP 登录码独立重放键**：同一验证码在时间窗内二次使用被拒；管理端身份绑定、改管理员邮箱、debug dump 正文下载补 step-up。
- **转发头解析加固**：仅在直连对端属于 `server.trusted_proxies` 时采信转发头，XFF 从右往左解析；伪造头不再绕过 API Key IP 白名单/会话绑定/蜜罐封禁键。
- **Responses WebSocket 帧重复字段**：拒绝帧内重复的 `service_tier`/`speed`/`reasoning.effort` 等计费与策略字段。
- **审计面**：OAuth/第三方登录与 2FA 挑战全路径落审计；应用日志邮箱统一脱敏；第三方 Action 全部 pin commit SHA。

## 运维前提

本版转发头解析依赖 `SERVER_TRUSTED_PROXIES`（生产已补齐回环与内网健康检查来源），nginx 需 `$proxy_add_x_forwarded_for` 追加。无数据库迁移。
