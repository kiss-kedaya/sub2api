# v2.1.11

## 用户能看到的变化

- 邀请返利：默认邀请码不动。每人可以再加最多 9 个自定义码，自己在邀请页管理，管理员也能代管。删自定义码不影响已经产生的返利。
- Gemini 分组里如果只放了 OpenAI 类型账号，模型列表不再是空的。
- 一组号都打满之后，服务端失败统一返回 529，方便客户端退避重试。上游明确返回的 503 仍保持 503。
- DeepSeek 同一工具调用重复出现时，调用和结果成对去掉，避免同一工具被跑两次。

## 管理后台

- 新增 TypeSafe / System One 平台，可建账号、配限额。
- 内容审计可以按引擎配置，支持 TypeSafe 引擎。

## 数据

- 新增迁移：内容审计引擎元数据、TypeSafe 平台约束、用户自定义邀请码表。
- 生产迁移模式仍是 validate。发版时单独执行迁移，不改运行配置。
