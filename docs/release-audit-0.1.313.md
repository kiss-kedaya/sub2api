## 可复用经验

1. 真实首字计时应区分响应头、SSE首事件、思考、正文、工具参数；requests默认iter_lines可能缓冲，不能只测总耗时。
2. usage必须跨取消、EOF、failed完整传到计费；可重试错误会让上层丢弃部分结果，取消后不能继续按重试处理。
3. Body.Close只在外层defer不够：handler若被Scan卡住，defer永远到不了。需要主循环取消/总预算与扫描器释放证据。
4. 不给断连硬塞1.5秒预算。真实上游可能仍在生成，复用现有预算并测试1.7秒之后的terminal usage。
5. 编译/单测不替代Linux lint。新增测试defer Close要显式处理错误；异步fixture清理要等待后台任务结束，不能重置正被使用的sync.Map。
6. 遇到5xx先保留证据并回退；再比较同一时段、同一路由错误，不能只看全站健康页或绝对错误数量。
7. 旧版始终保活，回退脚本可实测，所有流量切换仅graceful reload。发布文档明确当前比例、未完成验收和残余问题。
