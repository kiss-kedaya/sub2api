## 部署经验

335 的 API 检查通过后，实际资源验收发现 `/images/console-paper.webp` 与网关保留路由冲突并返回 404，已回退 334，335 标记为预发布。336 将图片内嵌 CSS，同时增加生产构建检查。今后不能只检查首页直接引用的 CSS；异步加载的背景 CSS、真实图片解码和两台 origin 的静态入口都必须验证，避免出现版本变了但页面资源未生效的情况。
