# Sub2API 0.1.354

## 测模型弹窗重新设计
- 删除工具栏重复的账号名和冗余并发说明，账号信息只保留一处。
- 统一青绿色主按钮、描边次按钮和低饱和停止按钮，全选/反选集中排列。
- 取消整行成功/运行色块，改用小型状态标签与细进度条。
- 模式与媒体提示词收进可折叠“测试设置”，保留填写内容。
- 优化结果展开、键盘焦点、深色模式、手机布局和减少动态效果偏好。
- 不更改测试请求、并发、取消、重跑和计费逻辑。

## 包含此前353功能
- 单账号与批量账号共用测模型结果表，支持筛选、勾选、测试全部/选中、停止及返回详情。
- 管理员工单显示今日Token、实际消费和近14天充值；查询失败不显示假零值。
- 支付宝/微信收银台超时显示新窗口与换网络提示，迟到加载后恢复。
- 移除访问白名单页面、菜单和用户API。
